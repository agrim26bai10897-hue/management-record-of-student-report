# Student Record Management System

A modular, command-line interface (CLI) application built in Python to streamline student record administration, demographic tracking, and academic performance evaluation.

---

## 📌 Project Overview
The **Student Record Management System** enables academic administrators and faculty to create, search, and manage student profiles while dynamically calculating academic metrics such as total marks, overall percentages, and pass/fail statuses. Designed using clean modular programming principles, the application separates data storage, academic processing, profile management, menu navigation, and system testing across distinct modules.

---

## ✨ Features
* **Direct Record Lookup:** Instantly view detailed student records using a unique Student ID.
* **Student Profile Registration:** Add new student records with fields for ID, Name, Age, Hosteller/Day Scholar status, State, Course, and Semester.
* **Academic Performance Engine:** Automatically calculate total marks, percentage, and overall result (`Pass`/`Fail`) based on 3-subject mark entries.
* **Marks Update:** Modify existing student marks and trigger real-time re-calculation of academic results.
* **Summary Reporting:** Display formatted terminal tables containing summary views of all enrolled students.
* **System Testing:** Built-in unit validation module to verify performance calculation accuracy.

---

## 🛠️ Technologies & Tools Used
* **Language:** Python 3.x
* **Core Concepts:** Dictionaries, Functions, Control Flow, Modular Imports, Testing (`assert`)
* **Environment:** Command Line Interface (CLI) / Terminal
